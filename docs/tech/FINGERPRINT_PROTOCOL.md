## 1. 帧结构(全双工同构)

```
+--------+----------+--------+---------+--------------+----------+
| 包头 6B | 标识码 1B | 长度 2B | 指令/数据 | 参数 ...      | 校验和 2B |
+--------+----------+--------+---------+--------------+----------+
  EF 01     0x01 指令   N          1B       ...           sum 低16位
  FF FF FF  0x02 数据
  FF FF     0x07 应答
            0x08 数据结束
```

- **包头**:`EF 01 FF FF FF FF`(模组地址默认 FFFFFFFF,不校验可变地址)。
- **长度**:标识码起的字节数(指令 1B + 参数 + 校验和 2B)。指令包 = 参数数+3。
- **校验和**:标识码起(含长度字节、指令、参数、不含包头)逐字节求和,取低 16 位,高字节在前。
- 字节序:多字节字段一律**大端**。

## 2. 指令集(码值已由官方例程冻结)

| Search | `0x04` | BufferID,StartPage(2B),PageNum(2B) | 确认码+页号(2B)+得分(2B) | 1:N 检索 | 例程逐字节【已冻结】 |
| RegModel | `0x05` | 无 | 确认码 | Buffer1+2 合成模板 | 例程逐字节【已冻结】 |

## 3. 应答帧(**长度字段口径与指令包不同,核心坑**)

**指令应答**(13B):`包头 + 07 0003 + 确认码 2B + 校验和 2B`。
例(成功):`EF01 FFFFFFFF 07 0003 0000 000A`。

**Search 应答**(17B):`包头 + 07 0007 + 确认码 2B + PageID 2B + 得分 2B + 校验和 2B`。
例(命中页 5 得分 50):`EF01 FFFFFFFF 07 0007 0000 0005 0032 0046`。

**ValidTempleteNum 应答**:`包头 + 07 0005 + 确认码 2B + 模板数 2B + 校验和 2B`。

**长度字段口径**:指令包 = 指令+参数+校验和;**应答包 = 确认码+参数+校验和再减 1**
(确认码 2B 只按 1B 计入),实际帧比长度字段多 1 字节——官方例程
`FPM10A_Receive_Data(12/16)` 少读一字节、`buffer[9]` 恰是确认码高字节,正是此坑。
解析器(fp_as608.c `after_len_of`)按标识码 0x07 折算 +1;结束包 0x08 同理特例
(长度 0x0003,校验和 = 标识码+长度字段)。校验和口径不受影响:恒为
标识码 + 长度字段 + 载荷(不含校验和)逐字节和的低 16 位。

**UpChar 数据包**(0x02):`包头 + 02 <数据长+2> + 特征数据 + 校验和 2B`;
随后**结束包**(0x08):`包头 + 08 0003 000B`。数据/结束包帧式为【标准推导】,
真机首连验证(§6.4)。

**确认码**(标准 AS608 语义,首连时逐条核):

| 码 | 含义 | 业务映射 |
|---|---|---|
| 0x00 | 成功 | 继续 |
| 0x01 | 收包错误(校验和/格式) | 重试一次,再失败计数降级 |
| 0x02 | 传感器无手指/采集不到 | 普通模式静默等待;录入提示重按 |
| 0x03 | 录入失败(特征太干/模糊) | 提示重按,不占进度 |
| 0x04 | 特征太干/太淡不成像 | 同上 |
| 0x05 | 合成失败(RegModel,两次差异大) | 同指校验兜底文案 |
| 0x09 | 未搜索到(1:N 落空) | 陌生人失败 |
| 0x0A | 模板已满 | DG_ERR_FINGER_FULL |
| 0x11 | 写 flash 错(Store/Delet) | 降级上报 |
| 0x15 | 缓冲区无有效图(流程顺序错) | 内部错误,计数 |

## 4. 串口参数

- **57600 8N1,无流控**(默认;模块支持指令改波特率,本产品不改)。
- 板侧约束(**2026-09-30 实测**):RK3576 板级 DTS 中 uart2~11 的 sclk 默认挂
  187.5kHz 慢时钟,上限 ~11.7k 波特——**uart8 必须在 DTS 显式 assigned 到
  24MHz**(写法抄调试口 uart0 节点),否则 57600 物理不通。

## 5. 业务指令序列(帧级)

- **1:N(普通模式)**:`GetImage → Img2Tz(B1) → Search(B1, 0, 999)`
  命中取应答 PageID → fingerprints 表反查 user_id。
- **1:1(验证按钮)**:`GetImage → Img2Tz(B1) → LoadChar(B2, 该用户 PageID_i) → Match`
  对该用户 ≤3 枚逐一 LoadChar+Match,任一成功即命中。
- **录入(两次按压)**:前置 `ValidTempleteNum` 查满 + DB 计数查限 →
  `GetImage → Img2Tz(B1) → Search(全库)` 查重 → 按压②
  `GetImage → Img2Tz(B2) → Match` 同指校验 → `RegModel → Store(B1, PageID)
  → UpChar(B1)` 读 512B → AES-256-CTR 加密落 fingerprints → 完毕。
  取消/退出:已 Store 则 `DeletChar(PageID,1)` 回滚 + 删行。
- **删除**:单枚 `DeletChar(PageID,1)` + 删行;删用户 = 逐枚 DeletChar(失败仍删行);
  恢复出厂 = `Empty` + 清表。
