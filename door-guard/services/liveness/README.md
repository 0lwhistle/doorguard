# liveness — 动作活体(单目 RGB 动作指令式,B8 已实装)

## 职责

按 `PROJECT_PLAN.md §4.4` 的产品定义,活体是"动作指令式"防伪:人脸在场即
随机下发 2~3 个动作(点头 / 摇头),用户在镜头前完成,全过才允许命中发布、
开门。本模块只做**判定**,不做业务决策;指令提示在 UI 顶层(`ui.c` 的
`lv_layer_top` 提示条),判定窗/步计时收口在 access FSM。

## 数据流

```
vision 后端(逐帧) ──liveness_service_on_face(5 关键点, 万分比)──▶ 本模块
                                                                      │
UI 顶层提示条 ◀──EV_LIVENESS_PROMPT(STEP 出题 / PASSED 通过 / HIDE 收起)─┤
access FSM   ◀──EV_LIVENESS_PROMPT(PASSED 武装 1.5s 判定窗;              ┤
                     STEP/PASSED 给 1:1 子步 5s 计时续命)                 │
vision 命中发布 ◀──liveness_service_pass()────────────────────────────┘ 门禁
```

- 关键点直调不走事件总线:帧率级频率 + 大数组,总线是命令/通知通道
  (架构纪律:大数据走直连);门禁是一次性查询,同样适合直调。
- 模式门:liveness 订阅 `EV_VISION_SET_MODE`,只在 `DETECT_1N/VERIFY_11`
  出题(菜单/待机/结果页 = DETECT_ONLY 不打扰);开机到首条 SET_MODE 之间
  按匹配态处理(开机默认即 DETECT_1N)。

## 判定算法(全部同轴比例,与帧宽高比无关)

5 点布局(RetinaFace 标准序):0 左眼 / 1 右眼 / 2 鼻尖 / 3 左嘴角 / 4 右嘴角。

| 动作 | 量 | 起幅 | 完成 |
|---|---|---|---|
| 摇头 | yaw = (鼻.x − 双眼中点.x)/眼距 | \|Δ\| ≥ 0.28 持续 4 帧 | 翻到对侧 ≥ 0.20 持续 4 帧 |
| 点头 | r = (鼻.y − 眼中点.y)/(嘴中点.y − 眼中点.y),Δ = r − 基线 | \|Δ\| ≥ 0.10 持续 4 帧 | 回到基线 ±0.04 持续 4 帧 |

- 基线:出场前 8 帧采、末 4 帧均值,出题时冻结;超时重出题时重采
  (人可能挪了位置)。
- 两轴解耦:点头用纯 y 比例、摇头用纯 x 偏移,转头/歪头的交叉影响是
  cos 级压缩,阈值已留余量;同轴比例对拍摄距离/分辨率天然不变。
- 防抖:判定沿需连续 4 帧(单帧漏检/分数抖动不计)。

## 状态机与放行语义

`IDLE → ARMING(8 帧)→ CHALLENGE(逐动作)→ PASSED(在场内粘滞)`

- 每步限时 `liveness_timeout_ms`(默认 5s),超时重出新序列(长度
  `liveness_actions_min~max` 随机,相邻动作不重复);
- 人脸离场(FACE_LOST 订阅 + 2s 无回灌双保险)→ 复位,**通过不继承给
  下一场**——照片顶替真人过闸的通道被堵死;
- `pass()` 只在 PASSED(或降级)时为 true;vision 的 `publish_gate()`
  以此拦命中。**活体未过 = 命中永远不下发**,FSM 的 1.5s 判定窗也由
  PASSED 事件武装(2026-10-25 起,检出不再开窗)——照片挡门只会被反复
  出题,不产生「陌生人失败」弹窗与日志。
- 1:1 人脸子步:动作完成沿(STEP/PASSED)给 5s 无操作步计时续命;照片
  无法借此挂住子步(没有完成沿,照样 5s 超时)。

## 降级路径(有意为之,与反欺骗同取舍)

`on_face` 点数 ≠ 5(ROCKIVA 106 点,布局未映射)持续 >2s → **降级放行**
并告警一次,离场恢复严格。理由:布局未知的点集上硬套 5 点几何 = 把门禁
变成「永远不开门」;与单帧反欺骗「模型缺失自动放行」同一取舍
(`cfg.h` 删除注)。rknn 主线恒 5 点,正常永不触发。

## 配置(`face.*`,见 services/config/README.md)

| 键 | 域 | 默认 | 说明 |
|---|---|---|---|
| liveness_actions_min | 1~3 | 2 | 序列最少步数 |
| liveness_actions_max | 1~3 | 3 | 最多步数(载入时 <min 抬到 min) |
| liveness_timeout_ms | 1000~10000 | 5000 | 单步限时 ms |

活体本身**恒启用无开关**(2026-10-04 用户拍板,`cfg.h` 删除注)。

## 能力边界(PROJECT_PLAN §4.4 原文口径)

可防静态照片、基础屏幕重放(随机动作+限时);**不能**防高清屏定向重放、
高仿真头模。量产安全等级要求高时升级 IR 双目,`liveness_service` 接口
不变换实现。单帧反欺骗(face_antispoof,MiniFASNet)与本模块正交并存:
前者拦"单帧就是假体",后者拦"连续帧重放"。
